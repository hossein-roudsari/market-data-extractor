# Market Data Extractor

A Python-based tool for extracting residential real estate market statistics from publicly available reports published by local real estate boards.

## Background
This project began as a practical solution to a manual repetitive workflow I encountered while working in real estate media production.

Market statistics were published monthly by different real estate boards, often in inconsistent formats. I developed this tool to automate the extraction of relevant metrics and organize them into Google Sheets for downstream use.

## Original Implementation
The original project includes:
- Report-specific extraction modules for different real estate markets
- PDF, CSV, webpage data extraction using Python
- Data processing and transformation with pandas
- Automated data acquisition using Selenium
- Google Sheets integration

## Project Status
Original implementation — initial public release.

This repository documents the starting point of the project. Planned improvements include modular architecture, improved validation, automated testing, structured JSON exports, historical data analysis, and additional data sources.
